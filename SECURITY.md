## 🛠 Troubleshooting

### Background remover not working

```powershell
# Clear Canva cache
Remove-Item "$env:APPDATA\Canva\cache" -Recurse -Force

# Restart Canva
taskkill /F /IM Canva.exe
Start-Process "C:\Program Files\Canva\Canva.exe"

# Ensure image resolution <25MP
# Image > Resize > Max 5000×5000px before removal
```

### Templates not loading

```powershell
# Reset template cache
.\Canva.exe --clear-templates

# Check internet connection
Test-NetConnection -ComputerName canva.com -Port 443

# Re-sync template library
.\Canva.exe --sync-library
```

### Export quality low

```powershell
# Change export settings
# Download > File type: PNG > Quality: High (300 DPI)

# For print: Use PDF Print format
# Download > PDF Print > Enable Crop Marks + Bleed

# For web: Use PNG with transparent background
```
